counter_2 Préparation des médias

Sélectionnez les médias...

  • Images : format jpg, png ou gif (Taille conseillée : 2048px)
  • Audios : format ogg ou mp3
  • Modèles 3D : format glb ou gltf avec textures incluses (10Mo max - 4Mo conseillé)

⚠️ Les noms de fichiers et de dossier ne doivent pas contenir de caractères spéciaux, ni accentués tels que : (&é~#à%*$ê/!_\/)

... puis copiez-les dans les dossiers suivants :

  • Pour les procédures : Copier ses médias dans le dossier de variante (📂MonReferentiel/📂MaVariante)>
  • Pour les évaluations : Copier ses médias dans le dossier "learn" de variante (📂MonReferentiel/📂MaVariante/📂learn)

support Aide

Fonctionnement

iXiMAKER Community est un éditeur visuel pour vous assister dans l'édition et la création de fichiers JSON iXi.
🆗 Il permet :

  • de simplifier la création de contenu XR
  • d'y associer les liens vers les fichiers média
  • de créer des fichiers JSON conformes au format iXi
  • d'importer et de modifier des fichiers JSON conformes au format iXi

🚫 Il ne permet pas :

  • de copier un fichier media dans le dossier (Version pro)
  • de spatialiser vos contenus (c'est le rôle de "iXiWORK - Place", gratuit)
  • de créer les dossiers de structure (Version pro)

Structure des fichiers au standard iXi

Pour fonctionner, les dossiers et fichiers doivent respecter l'organisation suivante :

  • 📁Nom du référentiel
    • 📁Variante
      • Referentiel_Variante.json (fichier des procédures qui va être créé)
      • 🧊modele1.bytes (les modèles 3D au format .glb ou .gltf, renommés en .bytes)
      • 🖼️Image1.png (Les images au format .png ou /jpg)
      • 🔊Audio1.ogg (les fichiers audio au format .ogg ou .mp3)
      • 📁learn
        • 📔Referentiel_Variante_learn.json (fichier des évaluations qui va être créé
        • 🧊modele1.bytes (modèles additionnels)
        • 🖼️Image1.png
        • 🔊Audio1.ogg
    • 📁Variante2...
