# iXiMAKER-Community
## Editeur de contenus no-code pour iXiWORK.
Ces 2 éditeurs permettent de créer et modifier de guidage opérationnels et des évaluations XR au standard iXi et :
- s'utilisent directement avec un simple navigateur internet,
- ne nécessitent pas de connexion,
- sont légers et compatibles avec la version PRO d'iXiMAKER disponible depuis ***iXiMANAGER***
## Utilisation
1. Téléchargez et décompressez l'archive 
2. Lancez index.html et créez vos variantes, procédures et évaluations
3. Spatialisez vos contenus avec ***iXiWORK "Place" - Community***, disponible gratuitement sur https://ixiverse.com par simple demande.
4. Distribuez librement vos contenus XR
## Fonctionnalités
- import de fichier JSON au format iXi
- classement par glisser-déposer
- aide sur chaque section (variante, procédures, évaluations)
